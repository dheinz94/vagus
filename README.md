# Vagus

Persönliches Dashboard für Erholung, Belastung, Schlaf und Bio-Alter auf Basis einer COROS-Uhr.
Läuft in Claude, im Browser und als iPhone-App (Safari → Teilen → „Zum Home-Bildschirm“).

- **App:** https://dheinz94.github.io/vagus/
- **Speicherdienst für den Geräteabgleich:** [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/dheinz94/vagus/tree/main/worker)

Dieses Repository enthält nur Programmcode. Gesundheitsdaten liegen auf deinen Geräten
und – verschlüsselt – in deinem eigenen Cloudflare-Speicherdienst.
